# Assignment 4 — Forms and Validation

Student: Kaiyr Abilmansur
Group: SE-2524

Five separate HTML pages demonstrate plain HTML forms, HTML5 validation, Bootstrap form styling, Bootstrap feedback, and a registration form.

## Pages
- `index.html` — Task 0: plain contact form
- `task1.html` — Task 1: built-in browser validation
- `task2.html` — Task 2: Bootstrap form and responsive grid
- `task3.html` — Task 3: JavaScript + Bootstrap validation
- `task4.html` — Task 4: registration form and validation

## How to run
Open `index.html` in any modern browser. Internet is needed for Bootstrap CDN assets. Use the navbar to navigate between tasks.

## Technologies
HTML5, CSS3, Bootstrap 5.3, vanilla JavaScript.

**Note:** Forms are demonstrations; no backend or database is connected. They do not actually deliver messages or create user accounts.
